## What is included

- Original reference images arranged under their corresponding module.
- Fresh README files written for this repository rather than copying the reference documentation.
- Small RTL examples for the concepts discussed in each module.
- Separate testbench examples where useful.
- Commands for simulation with Icarus Verilog and waveform viewing with GTKWave.
- Synthesis-oriented notes for Yosys.

## Suggested learning order

1. **Module 1:** Learn the RTL-to-simulation-to-synthesis flow using a simple multiplexer.
2. **Module 2:** Move into flip-flops, resets, constant multiplication, and hierarchy.
3. **Module 3:** Study constant-driven sequential logic and optimization opportunities.
4. **Module 4:** Compare mux coding styles, blocking-assignment caveats, and gate-level simulation.
5. **Module 5:** Practice `case`, `if`, `generate`, mux/demux structures, and incomplete assignments.
